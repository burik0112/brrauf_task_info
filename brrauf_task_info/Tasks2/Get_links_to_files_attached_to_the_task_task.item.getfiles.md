## Get links to files attached to the task task.item.getfiles

> Scope: [`task`](https://apidocs.bitrix24.com/api-reference/tasks/deprecated/task-item/api-reference/scopes/permissions.html)
> 
> Who can execute the method: any user

The method returns an array containing links to files attached to the task.

Method development has been halted

The method `task.item.getfiles` continues to function, but there is a more relevant alternative [tasks.task.get](https://apidocs.bitrix24.com/api-reference/tasks/deprecated/task-item/api-reference/tasks/tasks-task-get.html).

## Method parameters

| **Name** | **Description** |
| --- | --- |
| **TASKID** | Task identifier |
